My Blog App - Capstone Project 3
Hey there! I’m Anthony, and this is a blog app I built for my capstone project. It’s all about sharing updates on collegiate esports for Anthony Esports, and I’m super proud of how it turned out!
What My App Does

You can add, edit, and delete blog posts about esports.
There’s a dark mode toggle and it looks good on both your phone and computer.

How to Try It Out
Go to website: https://blog-web-application-capstone-project-3.onrender.com/

or 

Grab the code:git clone git@github.com:anthonyjomarq/Blog-Web-Application---Capstone-Project-3.git


Install the stuff it needs:npm install


Start it up:npm start


Check it out at http://localhost:3000.
